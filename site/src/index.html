# Why

macOS 27 draws the whole menu bar as one window. That broke every menu bar manager on the first beta, because they all moved the small per-icon windows that no longer exist. —tuck is built for the new bar instead of patched onto the old one.

# Use

  • Click ··· or press ⌃⌥M. Your tucked icons open in a panel.
  • Arrow keys move, a letter jumps, return opens, esc backs out.
  • Right-click ··· and choose Arrange Items. Hold ⌘ and drag icons across the “← tucked” line: left is tucked, right stays visible. Click ✓ when done.
  • Keep the drag on the bar. macOS removes an icon you drop off it.

# How it works

The divider is sized to the exact free space next to the notch. One point wider and macOS hides the divider itself. Four points narrower is fine: no icon fits in four points.

Icons it pushes out land in Apple’s own overflow. —tuck reads them through Accessibility and lists them.

Some icons would open their menu below the bottom of the screen. —tuck opens that menu where you can’t see it, copies it into the panel and closes it. Picking an entry presses the real one.

Apple’s « arrow stays. It’s a second door to the same icons, and removing it would take private APIs.

# Motion

Pointer actions animate. The panel grows out of ··· in 180 ms and leaves in 120 ms. Keyboard actions never animate: a shortcut you press forty times a day should not make you wait. With Reduce Motion on, only the fades remain.

# Install

git clone https://github.com/ulasalyesil/tuck
cd tuck && ./build.sh
open build/Tuck.app

Then allow Tuck in System Settings → Privacy & Security → Accessibility. It needs that to read and press other apps’ icons. It makes no network requests.

There is no signed download yet. You need macOS 27 and Xcode’s Swift toolchain.

# Limits

  • Popover icons hidden by the notch can only open their app, not the popover.
  • The panel shows app icons, not the menu bar glyph. The glyph would need Screen Recording.
  • Mirrored menus carry titles, check marks and submenus. Sliders and custom views don’t come through.
